# 做T交易规则

## 适用范围

本文件用于统一 Rachel Capital 在趋势股中的做T技术判断标准，适用于美团、腾讯、泡泡玛特、小米等处于上升趋势或趋势待确认阶段的核心持仓。

本文件讨论的是交易仓的卖出与买回纪律，不改变核心底仓的长期持有逻辑，也不替代个股基本面研究。

## 趋势股做T技术信号

### 一、放天量

“放天量”是指某个交易日的成交量或成交额明显高于近期正常水平，通常达到近20个交易日最高水平，或者较近期平均成交量放大约1.5倍至2倍以上。

放天量本身不等于卖出信号，必须结合股价走势和收盘位置判断。

#### 1. 放量突破

如果股价明显上涨，成交量显著放大，并且收盘价接近当天最高价，说明新增资金主动买入，上涨趋势仍然较强。这种情况通常属于放量突破，不应仅仅因为成交量大就卖出交易仓。

#### 2. 高位放天量

如果股价已经连续上涨或处于阶段高位，当天成交量达到近期极高水平，但股价冲高后明显回落，说明高位多空分歧加大，上方可能出现较强抛压。此时需要进入交易仓减仓观察状态。

### 二、长上影线

长上影线是指股价盘中曾明显上涨，但收盘时从最高价大幅回落，从而在K线上留下较长的上影线。

长上影线通常说明股价在高位遇到明显卖盘，但它不能脱离成交量和趋势位置单独使用。

判断上影线是否具有实际意义时，应重点观察：

- 当日最高价与收盘价之间的距离是否明显扩大。
- 上影线是否明显长于K线实体。
- 股价是否已经处于连续上涨后的相对高位。
- 当天成交量是否同步明显放大。
- 收盘价是否跌回重要压力位或突破位下方。

如果只出现长上影线，但成交量没有明显放大，可能只是普通的日内波动，信号可信度较低。

### 三、放天量与长上影的组合含义

“高位放天量、长上影、冲高回落”同时出现时，通常说明短线获利盘集中兑现，上方抛压明显增加，是趋势股交易仓较重要的高抛观察信号。

如果只有放天量，但股价收盘接近最高价，则更可能是放量突破，不应机械卖出。

如果只有长上影，但成交量较低，则暂不作为明确卖出依据，应继续观察后续一至两个交易日。

### 四、趋势股交易仓卖出四项确认

对于处于上涨趋势中的核心持仓，例如美团、腾讯、泡泡玛特或小米，不能仅凭单日上涨就卖出交易仓。

交易仓卖出时，优先检查以下四项信号：

| 信号 | 判断标准 |
| --- | --- |
| 单日涨幅明显 | 单日涨幅通常达到4%或以上。 |
| 成交量显著放大 | 成交量达到近20日高位，或明显高于近期平均水平。 |
| 出现明显长上影 | 盘中冲高后明显回落，上影线较长。 |
| 收盘明显低于最高价 | 收盘未能维持强势，体现冲高回落。 |

操作原则如下：

- 满足四项中的三项或四项时，可以认真考虑卖出部分交易仓。
- 只满足一项或两项时，原则上继续持有，避免在主升趋势中过早卖飞。
- 即使满足卖出条件，也只处理预先划定的交易仓，不动核心底仓。
- 卖出前必须同步制定买回条件。
- 不因股价继续上涨而情绪化追高买回。
- 技术信号必须结合公司基本面、市场环境和板块走势共同判断。

### 五、放量突破与高位出货的区别

| 项目 | 放量突破 | 高位出货风险 |
| --- | --- | --- |
| 股价位置 | 突破平台或压力位。 | 连续上涨后的相对高位。 |
| 成交量 | 明显放大。 | 明显放大或达到近期极值。 |
| 收盘位置 | 接近当天最高价。 | 明显低于当天最高价。 |
| 上影线 | 较短或没有。 | 较长。 |
| 后续策略 | 趋势优先，继续持有。 | 观察是否减交易仓。 |
| 核心仓处理 | 不动。 | 不动。 |

### 六、执行纪律

1. 做T不能只看涨幅，必须同时看成交量、K线形态和收盘位置。
2. 放天量不等于出货，放量上涨并收在高位通常属于强势信号。
3. 长上影不等于见顶，只有在高位、放量和冲高回落同时出现时，参考价值才明显提高。
4. 趋势股中，底仓收益通常比短期价差更重要，因此应减少无效交易。
5. 交易仓卖出后，如果没有达到预定买回条件，可以暂时踏空，但不能高于卖出价情绪化追回。
6. 每次使用该规则做出交易后，应在做T交易记录中补充实际结果，并复盘该信号是否有效。

## 交易纪律执行框架

### 一、交易纪律执行优先级

Rachel Capital 的交易决策必须遵循以下优先级：

1. 已确认的 Thesis 和 Trade Playbook 纪律。
2. 当前量价、资金和市场环境。
3. 主观趋势判断。

当既有交易纪律已经明确触发时，主观判断只能用于决定具体卖出比例、挂单价格和执行节奏，不能直接否定交易纪律。

例如，当股票连续2至3个交易日累计上涨超过8%，并接近 Thesis 中定义的重要压力位时，应进入交易仓利润兑现流程。即使分析仍然看好后续趋势，也应按照纪律分批卖出部分交易仓，而不是无限等待更高价格。

交易纪律允许卖飞部分交易仓，但不允许因为主观乐观而让已经获得的交易利润大幅回吐。

### 二、做T卖出纪律

仅使用交易仓做T，不动核心仓。

出现以下情况时，可以分批卖出交易仓：

| 条件 | 判断标准 |
| --- | --- |
| 单日大涨 | 单日上涨约3%至5%。 |
| 连续上涨 | 连续2至3个交易日累计上涨不低于8%。 |
| 接近压力位 | 股价接近 Thesis 或交易计划定义的重要压力区域。 |
| 高位异常量价 | 放量滞涨、长上影或冲高回落。 |
| 资金转弱 | 南向资金、主力资金或板块资金明显转弱。 |

执行规则如下：

- “连续上涨不低于8%并接近重要压力位”同时成立时，做T纪律即视为触发。
- 纪律触发后，原则上卖出交易仓的20%至30%。
- 如果资金面仍然较强且没有顶部K线，可先卖出20%。
- 如果同时出现放量滞涨、长上影或指数转弱，可卖出30%。
- 不要求所有风险信号全部出现后才执行。
- 核心仓不因短期技术信号被机械卖出。

### 三、每日交易纪律检查清单

每日分析个股前，必须先完成以下检查：

| 检查项目 | 触发标准 | 对应动作 |
| --- | --- | --- |
| 连续上涨 | 连续2至3日累计上涨不低于8%。 | 进入做T利润兑现检查。 |
| 单日大涨 | 单日上涨约3%至5%。 | 检查压力位及成交量。 |
| 接近压力位 | 接近 Thesis 定义的重要压力区域。 | 准备分批卖出交易仓。 |
| 成交量放大 | 成交量明显高于近期均量。 | 风险等级提高一级。 |
| 长上影 | 上影线明显长于实体且处于相对高位。 | 优先考虑兑现交易利润。 |
| 冲高回落 | 收盘明显低于盘中最高价。 | 检查是否减交易仓。 |
| 南向资金转弱 | 连续两个交易日明显净流出。 | 风险等级提高一级。 |
| 指数转弱 | 恒生科技指数放量跌破短期关键均线。 | 港股仓位进入防守观察。 |
| 正常回调 | 回调约3%至5%并接近支撑位。 | 检查是否分批买回。 |
| 财报或重大事件 | 财报、监管、重大公告前后。 | 暂停机械做T，重新评估 Thesis。 |

### 四、信号等级

每日分析应输出统一信号等级：

| 信号 | 含义 | 动作 |
| --- | --- | --- |
| 绿色 | 未触发交易纪律。 | 继续持有。 |
| 黄色 | 接近触发条件。 | 准备挂单，持续观察。 |
| 橙色 | 做T纪律已经触发。 | 卖出交易仓20%至30%。 |
| 红色 | 趋势、资金和基本面风险共振。 | 暂停加仓并评估进一步减仓。 |

### 五、每日分析输出顺序

以后对美团、腾讯、紫金矿业、三花智控、理想汽车及其他重点持仓进行分析时，输出顺序必须是：

1. 交易纪律检查结果。
2. 是否触发操作。
3. 明确的交易数量或比例建议。
4. 价格和量价执行条件。
5. 主观趋势分析。
6. 风险条件和后续观察点。

不得先输出主观趋势判断，再忽略已经触发的交易纪律。

### 六、复盘要求

如果事后发现交易纪律已经触发，但实际分析没有提醒执行，应在对应交易记录或月度复盘中记录以下内容：

- 哪条纪律已经触发。
- 当时为何没有执行。
- 对账户收益造成的影响。
- 后续如何避免相同错误。

## 使用要求

本规则用于统一技术标准，而不是机械替代判断。单一信号出现时，应优先确认趋势位置、量价配合和收盘强弱，再决定是否处理交易仓。

任何做T操作都必须遵守“核心底仓不动、交易仓单独管理、卖出前先定义买回条件”的原则。若技术信号与基本面、行业催化或市场环境明显冲突，应降低交易仓动作频率，避免因短线判断干扰长期收益。
