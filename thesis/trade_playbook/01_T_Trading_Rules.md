# 做T交易规则

## 适用范围

本文件用于统一 Rachel Capital 在趋势股中的做T技术判断标准，适用于美团、腾讯、泡泡玛特、小米等处于上升趋势或趋势待确认阶段的核心持仓。

本文件讨论的是交易仓的卖出与买回纪律，不改变核心底仓的长期持有逻辑，也不替代个股基本面研究。

## 趋势股做T技术信号

### 一、放天量

“放天量”是指某个交易日的成交量或成交额明显高于近期正常水平，通常达到近20个交易日最高水平，或者较近期平均成交量放大约1.5倍至2倍以上。

放天量本身不等于卖出信号，必须结合股价走势和收盘位置判断。

#### 1. 放量突破

如果股价明显上涨，成交量显著放大，并且收盘价接近当天最高价，说明新增资金主动买入，上涨趋势仍然较强。这种情况通常属于放量突破，不应仅仅因为成交量大就卖出交易仓。

#### 2. 高位放天量

如果股价已经连续上涨或处于阶段高位，当天成交量达到近期极高水平，但股价冲高后明显回落，说明高位多空分歧加大，上方可能出现较强抛压。此时需要进入交易仓减仓观察状态。

### 二、长上影线

长上影线是指股价盘中曾明显上涨，但收盘时从最高价大幅回落，从而在K线上留下较长的上影线。

长上影线通常说明股价在高位遇到明显卖盘，但它不能脱离成交量和趋势位置单独使用。

判断上影线是否具有实际意义时，应重点观察：

- 当日最高价与收盘价之间的距离是否明显扩大。
- 上影线是否明显长于K线实体。
- 股价是否已经处于连续上涨后的相对高位。
- 当天成交量是否同步明显放大。
- 收盘价是否跌回重要压力位或突破位下方。

如果只出现长上影线，但成交量没有明显放大，可能只是普通的日内波动，信号可信度较低。

### 三、放天量与长上影的组合含义

“高位放天量、长上影、冲高回落”同时出现时，通常说明短线获利盘集中兑现，上方抛压明显增加，是趋势股交易仓较重要的高抛观察信号。

如果只有放天量，但股价收盘接近最高价，则更可能是放量突破，不应机械卖出。

如果只有长上影，但成交量较低，则暂不作为明确卖出依据，应继续观察后续一至两个交易日。

### 四、趋势股交易仓卖出四项确认

对于处于上涨趋势中的核心持仓，例如美团、腾讯、泡泡玛特或小米，不能仅凭单日上涨就卖出交易仓。

交易仓卖出时，优先检查以下四项信号：

| 信号 | 判断标准 |
| --- | --- |
| 单日涨幅明显 | 单日涨幅通常达到4%或以上。 |
| 成交量显著放大 | 成交量达到近20日高位，或明显高于近期平均水平。 |
| 出现明显长上影 | 盘中冲高后明显回落，上影线较长。 |
| 收盘明显低于最高价 | 收盘未能维持强势，体现冲高回落。 |

操作原则如下：

- 满足四项中的三项或四项时，可以认真考虑卖出部分交易仓。
- 只满足一项或两项时，原则上继续持有，避免在主升趋势中过早卖飞。
- 即使满足卖出条件，也只处理预先划定的交易仓，不动核心底仓。
- 卖出前必须同步制定买回条件。
- 不因股价继续上涨而情绪化追高买回。
- 技术信号必须结合公司基本面、市场环境和板块走势共同判断。

### 五、放量突破与高位出货的区别

| 项目 | 放量突破 | 高位出货风险 |
| --- | --- | --- |
| 股价位置 | 突破平台或压力位。 | 连续上涨后的相对高位。 |
| 成交量 | 明显放大。 | 明显放大或达到近期极值。 |
| 收盘位置 | 接近当天最高价。 | 明显低于当天最高价。 |
| 上影线 | 较短或没有。 | 较长。 |
| 后续策略 | 趋势优先，继续持有。 | 观察是否减交易仓。 |
| 核心仓处理 | 不动。 | 不动。 |

### 六、执行纪律

1. 做T不能只看涨幅，必须同时看成交量、K线形态和收盘位置。
2. 放天量不等于出货，放量上涨并收在高位通常属于强势信号。
3. 长上影不等于见顶，只有在高位、放量和冲高回落同时出现时，参考价值才明显提高。
4. 趋势股中，底仓收益通常比短期价差更重要，因此应减少无效交易。
5. 交易仓卖出后，如果没有达到预定买回条件，可以暂时踏空，但不能高于卖出价情绪化追回。
6. 每次使用该规则做出交易后，应在做T交易记录中补充实际结果，并复盘该信号是否有效。

## 使用要求

本规则用于统一技术标准，而不是机械替代判断。单一信号出现时，应优先确认趋势位置、量价配合和收盘强弱，再决定是否处理交易仓。

任何做T操作都必须遵守“核心底仓不动、交易仓单独管理、卖出前先定义买回条件”的原则。若技术信号与基本面、行业催化或市场环境明显冲突，应降低交易仓动作频率，避免因短线判断干扰长期收益。
