### 每日需check的内容：

| 检查项目     | 触发条件               | 动作           |
| -------- | ------------------ | ------------ |
| 📈 连续上涨  | 连续2~3日累计上涨≥8%      | 进入做T观察       |
| 🎯 压力位   | 接近 Thesis 定义的重要压力位 | 卖出交易仓20%~30% |
| 📊 放量    | 当日成交量≥近5日均量1.5倍    | 风险等级+1       |
| 📉 长上影   | 上影线>实体2倍           | 优先兑现利润       |
| 💰 南向资金  | 连续2日明显净流出          | 风险等级+1       |
| 📉 恒生科技  | 跌破5日均线且放量          | 港股整体降仓观察     |
| 🔄 回调    | 回调3%~5%至重要支撑       | 分批买回交易仓      |
| ⚠️ 财报/政策 | 财报前后、重大监管事件        | 暂停做T         |

## Rachel Capital Daily Monitor 输出格式
### 纪律检查（优先级最高）
| 项目       | 状态 |
| -------- | -- |
| 连续上涨≥8%  | ✅  |
| 接近压力位    | ✅  |
| 放量       | ❌  |
| 长上影      | ❌  |
| 南向资金连续流出 | ❌  |
| 恒科指数转弱   | ❌  |

**纪律是否触发**
如果触发：根据 Thesis 做T原则，应卖出交易仓20%~30%。
如果没有触发：继续持有。

### 主观分析（第二优先级）
例如：今天虽然纪律触发，但板块资金仍然较强，因此建议先卖20%，保留80%交易仓，而不是卖30%。
也就是说：**纪律决定"做不做"，分析决定"做多少"。**
