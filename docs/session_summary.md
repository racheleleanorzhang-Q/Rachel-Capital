## 3. 本次新增的核心规则

### Rule A：资金流优先

任何个股交易之前必须先判断市场资金方向。

如果出现：

- 资金持续流出
- 所属板块弱于基准指数
- 个股成交量放大下跌

则：

暂停低吸补仓。

不能因为股票到达历史价格支撑位就机械买入。

### Rule B：相对强弱

买入判断不能只看绝对价格。

如果：

- 指数明显下跌
- 个股明显强于指数
- 个股率先止跌

可提高交易机会评分。

反之：

指数跌幅有限而个股明显弱于指数，则降低评分，不抄底。

### Rule C：价格区 ≠ 买卖信号

预设价格区只代表：

Observation Zone

不代表自动执行。

交易执行仍需结合：

- 分时止跌/止涨结构
- 成交量
- 板块资金
- 指数强弱
- Trade Playbook

### Rule D：核心仓 / 交易仓分离

核心仓：
- 获取中期趋势收益
- 不因普通日内波动卖出

交易仓：
- 用于日内T或波段T
- 用于锁定利润
- 用于降低持仓成本

禁止为了做T而卖飞核心仓。

### Rule E：日内T / 波段T必须标记

以后所有交易记录统一标记：

Strategy：
- 日内T（Intraday T）
或
- 波段T（Swing T）

并记录：

- Date
- Stock
- Action
- Price
- Quantity
- Strategy
- Status
- Reason
- Next Action
- Result（闭环后填写）

### Rule F：利润兑现

对于已经连续上涨且接近明显压力位的交易仓：

不要求卖在最高点。

达到压力区并出现：

- 冲高回落
- 放量滞涨
- 长上影
- 板块资金转弱

即可分批兑现交易仓。

### Rule G：不追跌卖出

普通回调阶段，不因为价格快速下跌而追跌卖出。

只有当：

- 趋势结构破坏
- 关键支撑有效跌破
- 板块/资金同步恶化

才升级为风险减仓。
