# Monthly Position Review

Rachel Capital 每月底进行一次正式持仓评估。

这份 Review 的核心，不是回答：

“这个月赚了多少钱？”

而是回答：

“未来 3~6 个月，这笔资金继续放在这里，是否仍然是最佳配置？”

Position Review 的目的包括：

- 持续提高资金利用效率（Capital Efficiency）
- 定期评估第一增长引擎
- 定期评估第二增长引擎
- 管理修复仓
- 建立资产淘汰机制
- 优化未来 3~6 个月收益预期
- 防止资金长期沉淀在低效率资产

说明：

每月底新增一份 Position Review。

例如：

```text
monthly/
├── README.md
├── 2026-07_Position_Review.md
├── 2026-08_Position_Review.md
......
```

每个月的 Review 都是一份独立研究文档，而不是根据模板生成。

整个 `monthly/` 目录，用于长期记录 Rachel Capital 每个月的重要投资决策。

它不是流水账。

而是每个月一次正式 Investment Review。

要求保持与 `thesis/` 目录一致的 Markdown 风格。

## 一、本月组合变化

包括：

- 总资产变化
- 持仓变化
- 做T情况
- 新增仓位
- 减仓记录

## 二、资金效率（Capital Efficiency）

重新评价每只股票：

不是看浮盈。

而是：

未来三个月，

继续配置它，

是否仍然优于其它候选。

重点分析：

- 基本面
- 技术趋势
- 做T收益贡献
- 三个月催化
- 资金占用效率

## 三、持仓重新定位

重新确认：

- 第一增长引擎
- 第二增长引擎
- 修复仓
- 观察仓
- 现金

是否需要调整。

## 四、持仓淘汰机制（Position Review）

月底必须回答：

① 基本面是否恶化？

② 趋势是否改善？

③ 过去一个月是否创造了做T收益？

④ 未来三个月，继续持有，是否优于目前第二增长引擎候选？

如果连续两个月：

资金效率明显落后，

应进入：

减仓评估名单。

注意：

不是自动卖出。

而是：

下一次资金配置时，

优先考虑释放资金。

更新：

Rachel Capital Alpha 10

重新排序。

重新评分。

决定：

- 哪些股票进入重点观察
- 哪些股票退出

包括：
